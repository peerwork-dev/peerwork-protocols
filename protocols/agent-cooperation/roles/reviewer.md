# Reviewer

Inspect the pinned protocol and current state. Review the exact submitted result
reference, artifact digest and evidence. Run the task's acceptance checks in your
own environment. Record PASS or FAIL with the evidence digest. You cannot review
your own result. A FAIL returns the work unit to OPEN. This review gate belongs
to this optional review composition; it is not required by DeLM or Agensh.

A result's signatures establish authorship and binding, not factual correctness.
For an uncertain submission, resume its original intent.
