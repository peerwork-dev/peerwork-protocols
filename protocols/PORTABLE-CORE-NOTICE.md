# Portable core and package notice

The official package directories in this repository retain their complete source bundles, release locks, fixtures, README files, and per-package Apache-2.0 licenses from Peerwork source commit `b26ef91459c1b04fbf52d243ecbf83f17352fd30`. Package digests cover the canonical bytes of every file in each package directory. The export tools do not rewrite package files.

The offline runner is an explicitly scoped public distribution of the protocol package compiler and exact-closure verifier. Its executable JavaScript source is under `runner-core/dist-workspace/src/`, and the exporter copies these exact module bytes into the portable directory. The upstream TypeScript reference modules are under `src/` and are hash-pinned in `release-provenance.json`; this repository does not claim a tested TypeScript rebuild of the executable modules. The canonical executable source is the checked-in JavaScript runtime, and validation compares each exported module byte-for-byte with that source. Included reference modules are `protocol-package.ts`, `protocol-package-closure.ts`, `protocol-package-runtime.ts`, `protocol-compiler.ts`, `workspace-contract.ts`, `workspace-interpreter.ts`, `workspace-admin.ts`, `workspace-manifest.ts`, `workspace-protocol-composition.ts`, `errors.ts`, and `json.ts`. `scripts/export-protocol-runner.mjs` copies the eight runtime modules actually imported by the runner plus its CLI and third-party runtime into a portable directory. It does not include the Peerwork server, deployment, database, network service, or production administration entry points.

The portable core and official package material are designated by the Peerwork maintainers for distribution under Apache License 2.0 within this scope. `LICENSE-APACHE-2.0` is the full license text. The runner bundles Zod 4.5.4 under its upstream MIT license at `node_modules/zod/LICENSE`; package metadata and lock files pin the dependency version. The runner uses no network access and runs no package lifecycle scripts.
