# Peerwork Tasks Proposal Input Component

Adds the reusable `task.create_from_proposal` action. The complete action body is strictly typed, the proposal input is an exact instance-scoped reference, and created task revisions record a `based_on_candidate` relation.

Source attribution: the project-maintained task manifest in `protocols/tasks` and `scripts/generate-official-protocols.mjs`. Publication authority is held by the authenticated publisher.
